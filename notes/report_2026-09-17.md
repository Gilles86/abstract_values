# Summary

- **Behaviour.** Bids are noisier in inverse-CDF sessions than in CDF sessions, whichever
  mapping came first, and collapse to near-zero noise at 22 CHF (the 90° anchor). The
  value-by-value noise profile does not follow value density.
- **Tuning.** V1 and NPCr both carry reliable stimulus tuning, within and across sessions.
  The mean responses cannot tell whether a region codes value or orientation: none of three
  cross-validated comparisons separates NPCr from V1, or even calls V1 orientation-coding.
- **Precision per condition.** Neural expected uncertainty in NPCr differs between
  conditions, but in the direction *opposite* to value density (r = −0.17, p = .016, with
  spherical noise and a dense decoding grid; the full empirical noise covariance inflated
  this to −0.61). That rules out a simple
  efficient-coding reading (and a simple orientation-coding one). Bid noise shows no
  density relation either. There is currently no evidence that neural or behavioural
  acuity follows the value prior.
- **NPCr–V1 coupling.** Trial-to-trial coupling between NPCr voxels and V1 orientation
  channels shifts between sessions toward the orientations worth the voxel's preferred
  value under the current mapping (p = 8·10⁻⁶). This is the one analysis that isolates
  value from orientation. It survives removal of neighbouring-trial leak and of per-trial
  gain, and is not confined to trials that drive the voxel.
- **Brain–behaviour.** Subjects with more tuned cortex bid more precisely (r = −.71), and
  the model's value-noise parameter tracks NPCr value precision (ρ = .62 [.26, .85]) while
  the crossed pairs do not — but the perceptual stage shows nothing, and coupling strength
  does not predict bid noise.

# 1. Task and behaviour

![**Task and behaviour.** **a** The two orientation-to-value mappings; both rise with
orientation but are warped differently. **b** Density of presented values per condition
(Gaussian kernel, SD 2 CHF; ticks: the 23 presented values). **c** Bid error SD per
presented value, mean ± SEM over subjects (n = 30).](figures/report_fig1_behaviour.pdf)

Bids are noisier under the inverse-CDF mapping: mean SD 1.69 vs 1.24 CHF,
t₂₉ = 4.98, p = 3·10⁻⁵. This holds in both session orders (inverse-CDF first:
+0.61 CHF; CDF first: +0.29 CHF; order difference p = .08), so practice alone does not
explain it. At 22 CHF (90°) bid SD falls to 0.33 CHF in both mappings, against 1.51 CHF
elsewhere (p < 10⁻¹¹): the cardinal category gate the efficient-coding models include.
Under CDF, SD dips at the dense values (~12 and ~32 CHF). Across the value range, however,
the CDF − inverse-CDF difference in log precision does not correlate with the difference
in log density (per-subject r = −0.04, p = .6; also with 18–26 CHF left out, p = .5).

# 2. Tuning in V1 and NPCr

![**Tuning, and why it cannot identify value coding.** **a** Split-half reliability of
per-voxel tuning (tuned voxels): V1 preferred orientation (circular r), NPCr preferred
value; within a session and across the two sessions. **b** Share of voxels (neutral
selection: the better model beats the null) where the joint value bump (`aprf.cv`) beats
its orientation-space twin (`vonmises-prf.cv`) on cvR². **c** Fitting tuning in one
condition and predicting the other by value vs by orientation (`condition_generalisation`).
Dots: subjects; diamonds: mean ± SEM.](figures/report_fig2_tuning.pdf)

Both regions carry reliable tuning. The split-half r is ~0.17 within a session and ~0.20
across sessions for both V1 orientation and NPCr value (all p < .001, n = 30). Deciding
*what* is tuned needs a between-session comparison: within a session value and
orientation are one-to-one. Neither comparison works:

- Value wins in 44 % of NPCr voxels and 45 % of V1 voxels (NPCr vs V1: p = .43).
- Predicting across conditions, orientation does slightly better in both regions
  (V1 Δr = −0.035, NPCr −0.042; NPCr vs V1: p = .61).

A test that cannot classify V1 as orientation-coding is insensitive rather than evidence
against value coding in NPCr. The two mappings differ by only ~4 CHF (~17°), which is
small next to tuning widths and between-session noise.

# 3. Precision per condition

![**Precision against the value prior.** **a** Log value density, CDF minus inverse CDF:
where efficient coding predicts relative precision (a population with fixed orientation
tuning predicts the same curve). **b** NPCr expected decoded SD per value and condition
(session-shift aPRF, simulated decoding, spherical noise, 200-point dense decoding grid;
n = 30). **c** Bid SD per value and condition
(n = 30). **d** Per subject, r across values between the CDF − inverse-CDF difference in
log precision and **a**.](figures/report_fig3_precision.pdf)

If precision followed the value prior, the precision difference between conditions would
correlate positively with the density difference (a). For NPCr expected uncertainty it
correlates *negatively*: r = −0.17 ± 0.07, t₂₉ = −2.57, p = .016 (−0.20, p = .006 when the
conditions are paired at the same orientation). Expected uncertainty is lowest around
22–28 CHF in the CDF condition, where CDF values are sparse. Two points follow:

1. Efficient coding and fixed orientation tuning both predict a positive relation, so the
   result fits neither. **Most of it is the noise model** (checked 2026-09-18,
   `eu_density_flatgrid.py`, `notes/figures/eu_density_flatgrid.pdf`). Re-running the same
   simulation while changing one choice at a time, and testing both across values and
   paired by orientation (the two mappings put a different density on the same
   orientation):

   | EU variant | across values | same orientation |
   |---|---|---|
   | Full empirical noise covariance, decode on the 23 presented values (used until 2026-09-17) | r = −0.61, p = 2·10⁻¹⁴ | −0.46, p = 6·10⁻¹⁴ |
   | Spherical noise, same grid | −0.19, p = .010 | −0.22, p = .004 |
   | Spherical noise, 200-point dense grid over the trained range | −0.17, p = .016 | −0.20, p = .006 |
   | Spherical noise, dense grid, condition's own value distribution as decoding prior | +0.08, p = .31 | −0.01, p = .89 |

   The full empirical Omega is what produced the dramatic effect; the project already
   prefers spherical noise for decoding for related reasons. The decoding grid barely
   matters in the real fits (contrary to a toy simulation with uniformly spread modes,
   where the presented-value grid alone gave r = −0.9). A small anti-density residual
   (≈ −0.2) survives with spherical noise and disappears once the decoder is given the
   condition's own value distribution as a prior, which is also what the modelled
   observer would use.
   Fisher information from the same fits (10 subjects) did track density (r = .27,
   p = .002), but that curve is also what orientation tuning alone predicts.
   **Everything in this report now uses the spherical-noise, dense-grid run**
   (`notes/data/expected_uncertainty_per_condition_spherical_dense.tsv`,
   `notes/data/brain_expected_uncertainty_spherical_dense.tsv`).
   A further reason not to read the session-shift EU as acuity: in the top-100 voxels
   half the fitted FWHMs are below 4.7 CHF and a quarter below 1.6 CHF — narrower than
   the spacing of the presented values — and 10 % of modes sit outside the 2–42 CHF
   range.
2. Bid noise shows no density relation (§1).
3. The trial-level decoders say the opposite of efficient coding in NPCr (added
   2026-09-18, `value_noise_basis_decoders.py`). With matched basis-set decoders
   (`--model weighted`, 100 voxels, spherical noise) and orientation fixed effects, the
   slope of log |residual| on log value density is +0.040 ± 0.020 (p = .047) in NPCr —
   more noise where values are dense — against −0.049 ± 0.024 (p = .043) in V1, the
   orientation-warp control (NPCr − V1: +0.089, p = .0004). The single-bump decoders give
   the same ordering, weaker (NPCr +0.015, V1 −0.027, difference p = .09). Decoding
   quality is the same for both model families (NPCr r ≈ .25, V1 r ≈ .50).
   NPCr behaving as if its value tuning has a fixed width, rather than being reallocated
   to the current value distribution, is consistent with the session-shift model
   comparison, where the no-shift model wins.

So neither neural nor behavioural precision currently shows value-prior-dependent acuity.
The efficient-coding models may still capture it through the full bias and variance
pattern (behaviour), but the model-free profiles do not.

# 4. NPCr–V1 coupling follows the current mapping

![**Coupling maps.** Row 1, prediction only: each NPCr voxel's value tuning read through
each session's mapping, averaged per 2-CHF preferred-value bin, over V1 orientation;
lines: θ\*, the orientation worth that value under each mapping. Row 2: the observed
trial-to-trial coupling maps (V1 channels from the inverted encoding model, 24 basis
functions, κ = 16; smoothed for display). **g** The observed difference map read along
the two θ\* curves. **h** Mapping score with gain controls. **i** Value- vs
orientation-winning NPCr voxels (selection favours value; see text).
](figures/cf_coupling_maps.pdf)

Per session, the mean response to each orientation is removed from every voxel. The
remaining trial-to-trial fluctuations of each NPCr voxel are correlated with V1
orientation channels. A coupling profile that is stable across sessions (anatomical
coupling, or orientation-tuned NPCr voxels) cancels in the between-session comparison.
What remains is coupling that moves with the mapping. For each voxel, the score is how
much better its coupling matches the prediction of the current mapping than that of the
other mapping; the label-shuffled score is subtracted.

| Analysis (n = 30) | Mapping score | p |
|---|---|---|
| All trials | +0.0161 | 8·10⁻⁶ |
| Neighbouring trials (±1) removed (8-bin channels) | +0.0114 | .0006 |
| Per-trial gain regressed out of both regions | +0.0100 | .02 |
| Low-drive half of trials | +0.0150 | .0001 |
| High-drive half of trials | +0.0095 | .01 |
| Observed vs predicted difference map (f vs c) | r = .062 | .0002 |
| Along θ\*: CDF ridge − inverse ridge (g) | +0.0104 | .003 |

- **Specificity.** The effect grows as V1 channels narrow: +0.009 with ~49° basis
  functions, +0.013 with ~24°, +0.016 with ~17°.
- **Gain.** Shared gain predicts the effect only on trials that drive the voxel; it is at
  least as large on low-drive trials. Gain regression does reduce it, and makes the
  map-level agreement non-significant (r = .021, p = .14).
- **Residual concerns.** Removing ±2 neighbouring trials halves it (p = .13), mostly
  because that model uses two thirds of the degrees of freedom. The reverse direction
  (V1 voxels as targets) is null, but its power was never established. The value- vs
  orientation-voxel split (i: +0.005, p = .035) was done within a selection that favours
  value voxels.

Details: `notes/connective_field_mapping_coupling.md`.

# 5. Brain–behaviour

![**Between subjects.** **a** Bid error SD against the number of orientation-tuned cortical
vertices (n = 26). **b** Cognitive-model parameters (sequential efficient-coding model,
long-term perceptual prior) against neural precision: matched pairs (blue: perceptual
precision κ_r ~ V1, value precision 1/σ_rep ~ NPCr) and crossed pairs (grey), for two
neural measures; Spearman ρ with 95% intervals over posterior draws × subject bootstrap
(n = 26). **c** Bid
SD against the NPCr–V1 mapping score (n = 30).](figures/report_fig5_brain_behaviour.pdf)

- **A strong general relation.** Subjects with more tuned cortex bid more precisely:
  r = −.71, p = 5·10⁻⁵. It survives partialling out head motion.
- **Half a stage-specific pattern** (updated 2026-09-18, with the spherical/dense-grid
  expected uncertainty and the long-term-prior sequential fit; the earlier table used a
  uniform-prior fit that is degenerate by construction). Value precision 1/σ_rep tracks
  NPCr value precision, ρ = .62 [.26, .85] — the matched pair, and the interval now
  excludes zero. The crossed pairs on the same measure do not: κ_r ~ NPCr ρ = −.07
  [−.46, .35]; 1/σ_rep ~ V1 ρ = .29 [−.14, .60]. Perceptual precision κ_r does not track
  V1 (ρ = .12 [−.35, .59]).
  The "tuned extent" measure still behaves like a general data-quality factor: there
  1/σ_rep correlates most with the extent of *orientation*-tuned cortex (ρ = .63
  [.30, .85]), a crossed pair.
- **Coupling.** Coupling strength does not predict bid noise (ρ = .17, p = .36).
- **Sample.** n = 26 in a–b: sub-01/02 are labelled `pil01/02` on the MRI side and
  sub-29/30 were not yet in the summary table.

## Reported value vs objective value (2026-09-18)

Two extra analyses ask whether these regions track what the participant *said* rather
than what the gabor was worth.

**aPRF fitted on the bid** (`model_specs.py: standard-bid`, with `standard-bidmatched` as
the objective-value control on exactly the same trials and voxels; leave-one-run-out,
NPCr + stimulated V1 band, n = 30). The bid model fits *worse* in both ROIs, and worse in
NPCr than in V1: ΔcvR² (bid − objective) = −0.0046 ± 0.0007 in NPCr (p = 8·10⁻⁷) and
−0.0021 ± 0.0006 in V1 (p = .002); NPCr − V1 = −0.0024 (p = .006).
The bid is the objective value plus report noise, so as a regressor it is simply worse;
this does not test subjective coding cleanly.

**Does the decoded value predict the bid beyond the truth?** Per subject, the partial
correlation between the decoded value of a trial and that trial's bid, with the objective
value removed from both (`decoded_predicts_bid.py`, n = 30):

| Decoder | V1 | NPCr | Next-trial control (V1 / NPCr) |
|---|---|---|---|
| 50 voxels | +0.085, p = 4·10⁻⁶ | +0.047, p = .0005 | −0.031 / −0.030 |
| 250 voxels | +0.069, p = 6·10⁻⁵ | +0.038, p = .002 | −0.033 / −0.019 |
| Basis set, 100 voxels | +0.083, p = 3·10⁻⁶ | +0.050, p = 5·10⁻⁵ | −0.027 / −0.021 |

Both regions carry the trial-by-trial part of the bid, and V1 carries more of it than
NPCr (NPCr − V1 ≈ −0.035, p = .05–.08). Shifting the bid by one trial removes it, so this
is not a slow drift. The natural reading is that perceptual noise in V1 propagates into
the bid; NPCr inherits part of it.

**Model parameters against decoding accuracy** (`brain_behavior_decoding.py`): using the
decoders' real out-of-sample accuracy instead of model-derived precision, the matched
value pair is the largest of the four (1/σ_rep ~ NPCr value decoding, ρ = .27–.37
depending on decoder) but its interval includes zero, and κ_r ~ V1 orientation decoding is
ρ = .09–.23, also including zero. Single-trial decoding accuracy is a noisier neural
measure than the model-derived expected SD, so this is a weaker version of §5's result,
in the same direction.

## Can we show that V1 is perceptual and NPCr is value? (2026-09-18)

Attempt: the report epoch. Within the gabor epoch value and orientation are one-to-one,
so nothing there can separate them; during the bid report the gabor is gone. Both one-bump
models were refitted on the GLMsingle response-epoch betas (`fit_aprf_cv --desc response`,
NPCr + V1 mask, n = 30, `epoch_dissociation.py`), each against a null model fitted on the
same betas.

| ROI | Epoch | Voxels above null: value / orientation |
|---|---|---|
| NPCr | Gabor | 27 % / 32 % |
| NPCr | Report | 31 % / 32 % |
| V1 | Gabor | 36 % / 38 % |
| V1 | Report | **50 % / 51 %** |

The report epoch does not isolate value: V1 is *more* predictable there than during the
gabor, and value and orientation predict it equally well. The obvious reason is that the
report epoch is visual — the response slider is on screen and its marker position carries
the bid, which correlates with the value. The formal interaction goes the wrong way as
well ((value − orientation) NPCr − V1 = −0.0017, p = .009).

So this does not make the point, and the mean-response comparisons in §2 do not either.
What might:

1. **Model the slider.** The marker's position is a visual variable that competes with
   value at the report epoch. It is not in the events files (the random initial position
   is not logged), so it would have to be reconstructed from the experiment code or logged
   in future sessions.
2. **Use the empty delay.** The 4–5.5 s ISI has nothing on screen. A timeseries GLM with a
   delay-period regressor (not GLMsingle) would ask whether value tuning survives when
   V1 has no input at all.
3. **Lean on how the ROIs are defined.** NPCr comes from an independent numerosity map and
   V1 from retinotopy; showing that value tuning in NPCr respects the numerosity gradient
   would tie the value code to that map rather than to the stimulus.
4. **The coupling analysis (§4) remains the one result that isolates value from
   orientation**, because anything orientation-driven cancels between sessions.

# 6. Open questions and next steps

1. **Is value coding in NPCr detectable from mean responses at all?** Estimate power for
   the value-vs-orientation comparison by simulating value-coding voxels at the observed
   noise. If it is underpowered by design, the coupling analysis is the main neural
   evidence for value.
2. **Precision.** Replace simulated decoded SD with a bias-free measure (Fisher
   information or discrimination thresholds from the fits). Test the prior prediction
   with the fixed-orientation-tuning curve as explicit null, not zero.
3. **Coupling.** Settle the neighbouring-trial leak at the source (re-estimated betas or
   residual timeseries). Establish power for the reverse direction. Add an anatomical
   control region.
4. **Brain–behaviour.** Refresh the subject summary to all 30 subjects (join `pil01/02`
   to 1/2). Settle which efficient-coding model variant is canonical before interpreting
   parameter correlations.
